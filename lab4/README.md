## Задача 1

### Текст задачи

Получить последовательность из максимальных цифр натуральных чисел, содержащихся в исходной последовательности

### Алгоритм решения

#### Ввод кол-ва элементов списка(с проверкой на корректность)
#### Вызов ввода элементов последовательности
#### Ввод элементов последовательноти
#### Обработка каждого элемента посл. используя Seq.map и функцию поиска максимальной цифры при вызове
